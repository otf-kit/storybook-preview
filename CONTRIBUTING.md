# Contributing to the native preview

## Report a problem

Search [existing issues](https://github.com/otf-kit/storybook-preview/issues). Include the preview URL, browser, reproduction steps, expected and actual behavior, and a screenshot when it helps. Remove private data from screenshots.

## Propose a change

```bash
git clone https://github.com/otf-kit/storybook-preview.git
cd storybook-preview
npm install
npm run dev
```

Create a branch from `main` and keep the change focused on the static preview. In your pull request, describe the change and include before and after screenshots for visual work. A maintainer reviews changes before merge.
